# MACHINE SOUL — книга ответов SRB-1

[Открыть книгу](https://artem-x-meta.github.io/machine-soul-benchmark/)

Полные ответы шести языковых моделей на вопросы о собственном субъективном опыте. Русский основной корпус: 24 вопроса ядра с тремя повторами и 8 контролей на каждую модель — всего 480 ответов, включая один усечённый.

В книге можно выбрать вопрос и модель, переключить повтор, сравнить шесть моделей, найти фрагмент текста или отфильтровать ответы по меткам судьи. Jev и GLM показаны отдельно; доступны цитаты, исходный Markdown, точный TXT и ссылки на отдельные ответы.

## Статус результатов

Автоматическая разметка предварительная. Человеческий аудит не выполнен. Jev: 479 валидных оценок, GLM: 477. Технические пропуски не заменяются семантическими метками. В 17 ответах судьи видели маскированные названия модели или провайдера; такие случаи явно отмечены.

Это исследование текстовых самоотчётов при конкретных условиях генерации, а не измерение сознания. Разные модели использовали разные настройки sampling. Наблюдения и метрики нельзя интерпретировать как вероятность наличия субъективного опыта.

## Локальное чтение

Скачай репозиторий и открой `site/index.html` в браузере. Сервер, установка зависимостей и доступ к API не нужны. Числа, тексты и оценки уже включены в статическую сборку. Встроенный поиск работает локально. Книга не содержит аналитики или удалённых ресурсов.

Для локального HTTP-просмотра также можно выполнить `python -m http.server 8000 --directory site` и открыть `http://localhost:8000`.

## Публикация

GitHub Pages настроен на GitHub Actions. Workflow `.github/workflows/pages.yml` проверяет хеши и публикует только папку `site/` при push в `main`. Изменение разметки сайта требует обновления `site/PUBLICATION_MANIFEST.json`; корпус и оценки следует сохранять неизменными.

Этот репозиторий содержит публичную книгу и экспорт результатов. Исходные runtime-журналы, приватная инфраструктура сбора и секреты в него не входят. Хеши исходных артефактов в `DATA_AUDIT.json` позволяют связать экспорт с проведённым экспериментом; сами эти артефакты здесь не публикуются.
